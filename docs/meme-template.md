一句话说清这是什么、梗在哪，不超过 60 字。这句会出现在目录卡片和页面描述里。

## 这个梗

它是什么，什么时候用，玩家为什么这么说。先讲人和事，再解释用法。

## 出处与来历

来源交代一次，然后接着讲事。每条来源一个链接（`npm run check` 要求至少一条）：

- [来源标题](https://example.com/…) —— 站点或简短说明
- [另一个来源](https://example.com/…) —— 说明

## 怎么用

群聊、论坛、战报里怎么出现。典型句式可用引用行：

> 某某：这句就是那个梗

## 变体与近亲

同一件事的其他叫法、上下游梗、容易混的词。提到已有词条时加互链，如 [另一个梗](/m/another-slug/)。

## 为什么好笑

一到两段锐评。笑点长在事实上，不靠形容词堆。
