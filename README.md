# EVE 梗指南

EVE Online 中文社区的**梗、黑话、名场面与圈内典故**，一条一页，讲清来历、怎么用，并且**逐条给出处**。

**👉 直接看：[sangshineboy.github.io/EVE-meme-guide](https://sangshineboy.github.io/EVE-meme-guide/)**

目前收录 **58 条词条** 与 **472 个黑话 / 术语**，覆盖国服（晨曦）与欧服（宁静）的旧事。

## 为什么做这个站

玩了十年 EVE，梗听了十年，却大多说不清出处：谁说的、什么时候、原话是什么，全靠"我记得"。

所以想把这些散在全网各处的说法收拢起来，**每条都追到能点开的原页面**，留给后来的人查。这也是它和一般"梗合集"的区别——这里不是段子集，是**带出处的梗台账**。

## 站上有什么

| 页面 | 能做什么 |
| --- | --- |
| **首页目录** | 按分类浏览，可按关键词、端游/手游、服务器筛选，也能按来源数或随机排序 |
| **词条页** | 一句话定义 + 这个梗 + 出处与来历 + 怎么用 + 变体与近亲 |
| **黑话索引** | 同一件事的三四个叫法都在这里，能对上词条的直接跳过去 |
| **出处总表** | 全站引用的链接按站点归拢，一眼看清这个站靠什么撑起来 |
| **全文搜索** | 搜词条名、别名、正文 |
| **随机翻一条** | 不知道看什么的时候用 |

## 内容是怎么来的

- 由 AI 从公开网络（贴吧、B站、百科、论坛、新闻等）搜集、摘要、改写，**人工核对格式与出处**。
- 每条词条的「出处与来历」都列出可点的原页面；**找不到出处的说法不收**。
- **死链不作出处**：原页面失效时，只保留能打开的二手转述，并在正文注明「原链接已失效」。
- 查不到的东西宁可不写，也不靠推测补齐。

## 请带着这份怀疑读

- **AI 会出错**：可能张冠李戴、把两件事揉成一件、把没核实的说法写得像定论。
- 内容**仅供参考**，不能当游戏机制说明、历史定论或对当事人的评价依据。
- 出处以**原页面为准**——原页面写错了，本站也会跟着错。
- 词条里的「社区流传」类说法多为一说之辞，正文会写明来路，不写成定论。
